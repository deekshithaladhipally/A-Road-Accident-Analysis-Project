Road Accident Analysis 
◦ Developed a project which analyzes road accident data in India over recent years to identify trends and key factors
like population density, safety accessory usage, vehicle types, road conditions, and timings.
◦ Focused on Machine learning algorithms which predict accident severity and highlight high-risk areas. Interactive
Power BI visualizations, including detailed charts and a 2020 report, will provide actionable insights to help policymakers and road safety authorities improve public safety and reduce accidents.
